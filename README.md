# 🎧 Audira - Interactive Headphone Landing Page

A modern, animation-rich landing page built with **Next.js**, **GSAP**, and **Tailwind CSS**.  
This project focuses on smooth scroll-based transitions, image morphing effects, and high-end UI storytelling.

---

## 🚀 [Live Preview](https://audira-gsap.vercel.app/)
https://audira-gsap.vercel.app/

---

## 📸 Features

- 🎬 GSAP ScrollTrigger-based animations
- ✨ SplitText animated hero heading
- 🎧 Smooth headphone image transition across sections
- 📱 Fully responsive (mobile + desktop optimized)
- 🎨 Modern UI with Tailwind CSS
- 🧠 Scroll-driven storytelling layout
- 🖼️ Image morphing between sections
- 🔥 Optimized Next.js Image component usage

---

## 🧱 Tech Stack

- Next.js (App Router)
- GSAP + ScrollTrigger
- GSAP SplitText plugin
- Tailwind CSS
